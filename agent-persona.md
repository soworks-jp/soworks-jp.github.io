## Public release status

Agent Persona is planned for public OSS release. The implementation is still being prepared behind a private repository while public packaging, examples, documentation, licensing, and release gates are finalized. Public repository and installation links will appear only after release readiness is complete.

## Product boundary

Persona packs make review perspectives explicit. They do not claim to simulate real people or replace interviews and direct user research. Public examples should stay synthetic or sanitized.
