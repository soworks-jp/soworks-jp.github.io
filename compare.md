## Quick decision

| If your main problem is… | Planned OSS project | Role in the stack |
|---|---|---|
| Multiple coding agents repeat work or lose task context | **[Agent Workbench](/agent-workbench/)** | Operate multi-agent tasks, ownership, handoffs, review and memory |
| Agents/editors read too much repository context | **[Agent Token Optimizer](/agent-token-optimizer/)** | Audit and optimize repository context before execution |
| AI review misses user/adopter/operator perspectives | **[Agent Persona](/agent-persona/)** | Add reusable human-perspective review lenses |
| You are researching explicit agent continuity | **[Agent Human Memory](/agent-human-memory/)** | Explicit memory, authority, provenance and forgetting |
| Reusable agent skills need packaging across tools | **[Agent Skill Shelf](/agent-skill-shelf/)** | Canonical skill source and multi-agent outputs |
| One output needs multi-perspective synthesis/judging | **[Fusion Skill](/fusion-skill/)** | Independent reviewer lanes and judge synthesis |
| Product ideas need briefs, PRDs and task plans | **AI Product Manager** | Product planning and structured implementation artifacts |
| Tasks need deterministic assignment before execution | **Agent Task Router** | Route work to agents, model tiers, skills or human gates |
| Structured tasks need target-specific handoff packets | **Agent Handoff Kit** | Render agent-ready handoff packets |
| Agent activity needs reports, risks and next actions | **Agent Reporting** | Explain runs, failures, learning and next actions |
| Developer-machine performance is slowing agent work | **Agent Machine Doctor** | Diagnose machine health and developer-tool performance |
| Repository / agent security needs a release gate | **Agent Security Doctor** | Security diagnostics and release gating |
| Human approvals/results need Slack or Discord delivery | **Agent Channel Bridge** | Human-in-the-loop external channel bridge |

All 13 projects are planned for public OSS release. Until each repository or package is actually accessible, the public site shows product direction and synthetic previews rather than private links, unpublished install commands, or public recruitment flows.

<div class="sw-callout"><strong>Portfolio rule:</strong> the complete roadmap is public, but availability is not implied. Release links are added only when each project clears its packaging, documentation, licensing, and safety gates.</div>
